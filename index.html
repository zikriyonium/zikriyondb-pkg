ZikriyonDB

A small, crash-safe SQL database with a built-in HTTP API, made for websites written in plain HTML, JavaScript and PHP. It runs on servers, Raspberry Pis and phones, and can publish itself on a public HTTPS address without router setup.

Install (Debian, Ubuntu)

curl -fsSL https://zikriyondb.zeaipc.info/install.sh | sudo sh

This adds the signed ZikriyonDB repository and runs apt install zikriyondb. Afterwards:

sudo cat /etc/zikriyondb/admin.key        # your administrator key
curl http://127.0.0.1:7860/v1/health
zikriyonctl help

Other Linux: the same command installs signed static binaries to /usr/local/bin. To host your own relay: ... | sudo sh -s -- relay.
